# L'Aura Sahara - 3D Cylinder Restaurant Menu

This project is configured with GitHub Actions to automatically deploy to GitHub Pages on every push to `main` or `master`.

## Setup Instructions

1. Ensure your GitHub Repository **Settings > Pages** has **Build and deployment > Source** set to **GitHub Actions**.
2. Push your changes to `main` or `master`.
3. Watch the Actions tab for successful build and deployment!
